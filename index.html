🤔 What is snifftest?

snifftest is a clever little tool that scans your writing for common AI tells — those subtle, repetitive patterns that give away when text was written by a language model. Think of it as a spellchecker, but for robotic writing style instead of typos.

It comes with countable rules (over 30 built-in checks) and a special judgment model that evaluates the flowof your prose. You get a clear, plain-language report on what might look artificial, so you can rewrite it naturally.

Best of all? It has zero dependencies — no complex installs, no bloatware, no headaches. It just runs.

🛠️ How to Use It (Non-Coder Edition)

You don't need a terminal to use snifftest — but if you're feeling adventurous, here are two easy ways.

🖱️ Method A: Use the Visual App (Recommended)

  1. Open snifftest from your Start Menu or Desktop icon.
  2. Drag any .md file into the window.
  3. Read the clean report. Click any flagged line to see a rewrite suggestion.
  4. Hit "Copy" to grab the improved version, or "Export" to save a fixed copy.

⌨️ Method B: For the Slightly Curious — Command Line

  1. Open Command Prompt (Press Win key, type cmd, Enter).
  2. Type the command, replacing the file path:
  3. snifftest "C:\Users\You\Documents\mydoc.md"
  4. Press Enter. You'll see a colorful line-by-line report right in the window.

That's it. No configuration files. No flags. Just write, run, and polish.

🩺 Troubleshooting (Windows Made Simple)

  • Windows SmartScreen warning? That just means Microsoft hasn't seen the app often. Click "More info" → "Run anyway." Safe, promise.
  • Can't find the button to download? Head to the "Releases" tab on the GitHub page. The latest release is on top.
  • It says "File not found" when you run it? Double-check that your file has a .md extension. Snifftest works on Markdown by design.
  • No report appears? Make sure your file isn't completely empty. Snifftest needs at least three sentences to analyze.
